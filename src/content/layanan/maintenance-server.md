## Jangan Tunggu Sampai Server Down Baru Cari Bantuan

Website lambat. Email notifikasi tidak terkirim. Plugin usang jadi celah keamanan. Masalah-masalah ini tidak muncul tiba-tiba — mereka menumpuk perlahan, dan meledak di saat paling tidak tepat: saat traffic tinggi, saat deadline submission, saat tim Anda sedang libur.

Layanan **maintenance & dukungan teknis** dari Motekarindo memastikan sistem Anda tetap sehat — bukan sekadar diperbaiki saat rusak. Setiap tindakan tercatat. Setiap perubahan terdokumentasi. Anda selalu tahu apa yang terjadi di server dan aplikasi Anda.

### Masalah yang Terjadi Tanpa Maintenance Rutin

- **Server dibiarkan tanpa update:** Versi PHP usang, library tidak di-patch — celah keamanan menganga lebar.
- **Backup tidak pernah dicek:** File backup ada, tapi siapa yang tahu bisa direstore atau tidak? Saat dibutuhkan, ternyata korup.
- **Notifikasi tidak terkirim:** Email OJS gagal, password reset gagal, user komplain — tapi tidak ada yang sadar sampai berminggu-minggu.
- **Tidak ada yang tahu kondisi server:** CPU usage, disk space, memory — semua tidak terpantau. Server mati mendadak saat storage penuh.
- **Developer sudah tidak bisa dihubungi:** Satu-satunya orang yang paham sistem sudah pindah kerja — tidak ada dokumentasi, tidak ada yang bisa mengambil alih.

### Yang Membuat Maintenance Kami Berbeda

- **Dokumentasi lengkap** — Setiap perubahan, update, atau perbaikan dicatat dalam changelog yang bisa Anda akses. Tidak ada yang off the record.
- **Backup teruji** — Kami tidak hanya menjalankan backup otomatis — kami uji restore secara berkala untuk memastikan data Anda benar-benar bisa dipulihkan.
- **Transparansi penuh** — Dashboard monitoring bisa Anda akses sendiri. Anda tahu kondisi server Anda kapan saja, tanpa harus bertanya ke kami.
- **Tidak ada lock-in** — Semua kredensial dan dokumentasi adalah milik Anda. Jika suatu saat ingin pindah ke vendor lain atau membangun tim internal, proses transisi mudah karena semua informasi sudah ada di tangan Anda.

### FAQ

> [!tip]+ **Apakah paket maintenance bisa dikustomisasi?**  
> Ya. Setiap kebutuhan berbeda — kami bisa sesuaikan cakupan layanan, frekuensi backup, response time, dan SLA. Hubungi kami untuk diskusi kebutuhan Anda.

> [!tip]- **Apakah ada biaya setup awal?**  
> Untuk server yang belum pernah kami kelola, ada biaya audit awal (one-time) untuk mengecek kondisi existing. Audit ini menghasilkan laporan yang bisa Anda pakai — bahkan jika Anda memutuskan tidak lanjut dengan kami.

> [!tip]- **Berapa minimal kontrak?**  
> Tidak ada kontrak minimal. Bisa bulanan — berhenti kapan saja. Untuk paket Professional dan Enterprise, kami rekomendasikan minimal 3 bulan agar transisi dan dokumentasi berjalan optimal.

> [!tip]- **Apakah bisa menangani server yang bukan di-install oleh Motekarindo?**  
> Ya. Justru ini salah satu kasus paling umum. Kami ambil alih server yang sudah berjalan, audit kondisinya, susun dokumentasi dari awal, lalu kelola sesuai standar kami.

> [!tip]- **Apakah dukungan teknis hanya via chat?**  
> Via WhatsApp untuk komunikasi harian dan insiden. Untuk troubleshooting yang butuh screen sharing, kami bisa via Google Meet atau Zoom. Semua komunikasi penting kami dokumentasikan.
