## Repositori Institusi Siap Online — Tanpa Pusing Teknis

EPrints adalah platform repositori digital open source yang dipakai kampus dan institusi penelitian untuk mengelola karya ilmiah — skripsi, tesis, disertasi, dan publikasi dosen. Tapi di balik fungsinya yang vital untuk akreditasi dan pelaporan, proses instalasinya bisa jadi rumit: dependency Perl, konfigurasi MySQL, sampai OAI-PMH yang tidak kunjung terindeks.

Kami menginstal dan mengonfigurasi ePrints secara menyeluruh. Setiap instalasi disertai **dokumentasi lengkap** — sehingga repositori Anda tidak hanya online, tapi benar-benar siap diisi dan diakses.

### Tantangan Mengelola ePrints Secara Mandiri

- **Dependency Perl yang rumit:** ePrints berjalan di atas Perl dengan banyak modul pendukung. Versi yang tidak cocok membuat instalasi gagal di tengah jalan — error yang tidak semua admin server pahami.
- **Konfigurasi MySQL & Apache:** ePrints butuh pengaturan database dan web server yang spesifik. Salah konfigurasi = repositori lemot atau tidak bisa diakses.
- **Metadata tidak konsisten:** Tanpa setup metadata (Dublin Core) yang benar, dokumen sulit dicari, sulit terindeks, dan laporan institusi jadi tidak akurat.
- **OAI-PMH tidak jalan:** Protokol harvest metadata ini wajib agar repositori Anda terindeks di agregator nasional seperti Rama, Indonesia OneSearch, dan Portal Garuda. Kalau tidak aktif, karya ilmiah Anda tidak ditemukan.
- **Tidak ada dokumentasi:** Setelah instalasi, pengelola bingung: cara deposit dokumen, cara approval, cara backup — tidak ada panduan tertulis.

### Yang Kami Kerjakan

1. **Instalasi ePrints Versi Stabil** — Kami pasang versi terbaru yang stabil, lengkap dengan semua dependensi (Perl, MySQL/MariaDB, web server). Semua dicatat: apa yang diinstal, versi berapa, kenapa.
2. **Konfigurasi Metadata (Dublin Core)** — Setup subject, jenis dokumen, dan skema metadata agar setiap karya terekam konsisten dan mudah dicari. Fondasi untuk laporan akreditasi yang akurat.
3. **Setup OAI-PMH** — Aktifkan dan uji protokol harvest metadata agar repositori Anda siap diindeks agregator nasional dan internasional.
4. **Dokumentasi Pengelolaan** — Panduan tertulis: cara deposit, cara approve, cara tambah user/role, cara backup database, dan troubleshooting umum. Diserahkan saat go live.
5. **Backup & Optimasi Dasar** — Setup backup otomatis, SSL, dan konfigurasi web server agar repositori berjalan optimal.

### Proses Instalasi

1. **Cek Kesiapan Server** — Kami periksa spesifikasi server Anda (atau bantu siapkan VPS baru). Persyaratan teknis dicek: versi Perl, modul, database, kapasitas penyimpanan. Kalau ada yang kurang, kami beri tahu sebelum mulai.

2. **Instalasi & Konfigurasi** — Download ePrints, atur dependensi, buat database, jalankan wizard instalasi, konfigurasi dasar. Semua tahap dicatat.

3. **Serah Terima** — Kredensial admin, URL repositori, dan dokumen panduan diserahkan. Kami tunjukkan cara mengelola repositori — Anda bisa tanya langsung di sesi ini.

### FAQ

> [!tip]+ **Berapa lama sampai repositori siap?**
> Instalasi standar: 2-3 hari kerja. Kalau server sudah siap, bisa lebih cepat. Untuk konfigurasi khusus atau migrasi dari versi lama: 1-2 minggu. Estimasi detail diberikan setelah cek kebutuhan.

> [!tip]- **Apakah bisa install di server kampus yang sudah ada?**
> Ya. Kami install langsung di server Anda — VPS kampus, cloud, atau dedicated server. Syarat: akses SSH dan memenuhi spesifikasi teknis ePrints. Kalau server belum ada, kami bantu siapkan.

> [!tip]- **Apakah termasuk training pengelola repository?**
> Dokumentasi pengelolaan selalu disertakan. Untuk training yang lebih mendalam (cara deposit, cara approve, cara kelola user), tersedia sebagai sesi terpisah — bisa via Zoom atau onsite.

> [!tip]- **Bagaimana jika ingin migrasi dari versi ePrints lama?**
> Kami berpengalaman melakukan upgrade dan migrasi ePrints — termasuk repositori dengan ribuan dokumen. Semua dilakukan di staging environment dulu, diuji, baru diterapkan ke production. Nol data hilang.

> [!tip]- **Apakah mendukung OAI-PMH untuk agregator nasional?**
> Ya. Setup OAI-PMH termasuk dalam instalasi. Repositori Anda siap diindeks oleh Rama, Indonesia OneSearch, Portal Garuda, dan agregator internasional lainnya.

> [!tip]- **Apakah ada garansi setelah instalasi?**
> Masa garansi 2 minggu untuk perbaikan bug terkait instalasi. Setelah itu, tersedia layanan maintenance bulanan — termasuk monitoring, backup harian, dan update keamanan.
