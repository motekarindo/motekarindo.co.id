## Aplikasi Terpasang, Siap Pakai — Tanpa Pusing Konfigurasi

Butuh OJS untuk jurnal kampus? ePrints untuk repository institusi? Atau aplikasi custom yang perlu di-deploy ke server? Instalasi aplikasi terdengar sederhana — sampai Anda berhadapan dengan dependency error, permission issue, atau konfigurasi yang tidak jelas dokumentasinya.

Kami tidak sekadar install dan pergi. Setiap instalasi disertai **dokumentasi konfigurasi**, daftar akses, dan panduan pengelolaan dasar — sehingga tim Anda bisa langsung menggunakan aplikasi tanpa bergantung pada kami.

### Aplikasi yang Kami Pasang & Konfigurasikan

1. **Open Journal Systems (OJS)** — Platform manajemen jurnal ilmiah open source. Kami install, konfigurasi, setting email notifikasi, dan pastikan alur editorial berfungsi — dari submission, review, hingga publishing.

2. **ePrints** — Repository digital untuk karya ilmiah, skripsi, tesis, dan dokumen akademik. Kami setup, konfigurasi metadata dasar, dan uji upload dokumen.

3. **WordPress** — CMS paling populer di dunia. Instalasi, pemilihan tema, plugin esensial (SEO, security, caching), dan optimasi dasar.

4. **Aplikasi Web Custom** — Punya aplikasi dari developer lain yang perlu di-deploy? Kami bantu: setup environment, konfigurasi database, deploy kode, dan pastikan berjalan sesuai spesifikasi.

### Yang Termasuk dalam Layanan Instalasi

- **Environment check** — Kami periksa spesifikasi server: versi PHP, database, ekstensi yang diperlukan. Kalau ada yang kurang, kami beri tahu sebelum instalasi dimulai.
- **Instalasi & konfigurasi** — Aplikasi dipasang sesuai best practice. Path, permission, dan environment variable disetel dengan benar.
- **Uji fungsi dasar** — Kami uji fitur utama: login, input data, output. Semua dicek sebelum dinyatakan siap.
- **Dokumentasi serah terima** — URL akses, kredensial admin, panduan dasar, dan catatan teknis diserahkan dalam satu dokumen.

### Proses Instalasi Kami

1. **Cek Kesiapan** — Kami periksa server Anda (atau bantu siapkan jika belum punya). Semua persyaratan teknis dicek: versi software, ekstensi, kapasitas penyimpanan.

2. **Instalasi** — Aplikasi dipasang, dependensi diurus, konfigurasi awal disetel. Proses transparan — Anda tahu apa yang sedang dikerjakan.

3. **Uji Coba** — Fitur utama diuji: login, input/output, workflow dasar. Bug atau error langsung dicatat dan diperbaiki.

4. **Serah Terima** — Kredensial, URL, dan panduan dasar diserahkan via dokumen. Kami tunjukkan cara mengelola aplikasi — Anda bisa tanya langsung di sesi ini.

### FAQ

**Berapa lama proses instalasi?**  
Instalasi OJS/ePrints standar: 1-3 hari kerja. Instalasi dengan custom theme atau konfigurasi khusus: 3-7 hari kerja. Estimasi detail diberikan setelah cek kebutuhan.

**Apakah bisa instalasi di server yang sudah ada?**  
Ya. Kami bisa install di server Anda sendiri, atau bantu siapkan VPS baru jika diperlukan. Yang penting server memenuhi persyaratan teknis aplikasi.

**Apakah termasuk training penggunaan?**  
Dokumentasi pengelolaan dasar selalu disertakan. Untuk training tim yang lebih mendalam (misalnya: melatih editor OJS atau admin ePrints), tersedia sebagai layanan terpisah.

**Apakah bisa upgrade versi aplikasi?**  
Ya. Kami bisa bantu upgrade OJS dari versi 2 ke 3, atau ePrints ke versi terbaru — termasuk migrasi data. Semua dilakukan di staging dulu, diuji, baru diterapkan ke production.

**Bagaimana jika aplikasi error setelah instalasi?**  
Kami beri masa garansi 1-2 minggu pasca instalasi untuk perbaikan bug terkait instalasi. Di luar itu, tersedia layanan maintenance terpisah dengan response time yang disepakati.
