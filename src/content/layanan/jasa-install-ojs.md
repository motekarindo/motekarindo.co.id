## Jurnal Ilmiah Siap Online — Tanpa Pusing Teknis

Open Journal Systems (OJS) adalah platform jurnal ilmiah open source paling populer di dunia — dipakai oleh ribuan jurnal di Indonesia. Tapi di balik kemudahannya untuk editor dan author, proses instalasi dan konfigurasinya bisa jadi mimpi buruk: PHP version conflict, dependency error, email notifikasi gagal, permission kacau.

Kami sudah menginstal dan mengelola OJS untuk beberapa jurnal terakreditasi SINTA. Setiap instalasi disertai **dokumentasi lengkap** dan **uji alur editorial penuh** — dari registrasi author sampai artikel published. Tim editor Anda tinggal fokus ke substansi artikel, bukan urusan teknis.

### Tantangan Mengelola OJS Secara Mandiri

- **Instalasi teknis rumit:** OJS butuh versi PHP spesifik, ekstensi tertentu, database MariaDB/MySQL, dan permission folder yang tepat. Satu langkah salah — aplikasi error atau tidak bisa diakses.
- **Email notifikasi gagal kirim:** Submission confirmation, review request, editorial decision — kalau email tidak terkirim, proses review macet. Konfigurasi SMTP di OJS tidak semudah centang-centang.
- **Server tidak optimal:** Shared hosting murah bikin OJS lemot. Di sisi lain, VPS butuh setup yang tidak semua pengelola jurnal kuasai.
- **Tidak ada dokumentasi:** Setelah instalasi, admin bingung: cara tambah user, buat issue baru, backup database — tidak ada panduan tertulis. Akhirnya tergantung terus ke satu orang yang paham.
- **Upgrade bikin panik:** Mau upgrade dari OJS 2 ke 3? Ribuan artikel, ratusan user, plugin kustom — kalau salah langkah, data hilang.

### Yang Kami Kerjakan

1. **Instalasi OJS Versi Terbaru** — Kami pasang versi stabil terkini, lengkap dengan semua dependensi (PHP, database, ekstensi). Permission disetel dengan benar. Semua dicatat: apa yang diinstal, versi berapa, kenapa.

2. **Konfigurasi Email Notifikasi** — Setup SMTP relay (bukan PHP mail) agar seluruh notifikasi — submission, review, editorial decision — terkirim dengan deliverability tinggi. Kami uji kirim dan uji terima.

3. **Uji Alur Editorial Penuh** — Dari registrasi author → submission artikel → assignment reviewer → review → revisi → copyediting → publishing. Semua peran kami uji sebelum dinyatakan siap pakai.

4. **Setup Dasar Jurnal** — Konfigurasi nama jurnal, ISSN, fokus & scope, template artikel, dan pengaturan dasar lainnya — sehingga tim editor bisa langsung bekerja tanpa mulai dari nol.

5. **Dokumentasi Pengelolaan** — Panduan tertulis: cara tambah user/editor/reviewer, cara buat issue baru, cara backup database, cara update plugin, dan troubleshooting umum. Diserahkan saat go live.

6. **Optimasi Dasar Server** — Setup caching, kompresi, SSL, dan konfigurasi web server agar OJS berjalan optimal. Siap untuk traffic ribuan visitor per bulan.

### Proses Instalasi

1. **Cek Kesiapan Server** — Kami periksa spesifikasi server Anda (atau bantu siapkan VPS baru). Semua persyaratan teknis dicek: versi PHP, ekstensi, kapasitas penyimpanan. Kalau ada yang kurang, kami beri tahu sebelum mulai.

2. **Instalasi & Konfigurasi** — Download OJS versi terbaru, ekstrak, atur permission, buat database, jalankan wizard instalasi, konfigurasi dasar. Semua tahap dicatat dalam log.

3. **Setup Email & Uji Alur** — Konfigurasi SMTP, uji kirim notifikasi ke semua peran. Verifikasi alur editorial lengkap: submission → review → publishing. Bug atau error langsung diperbaiki.

4. **Serah Terima** — Kredensial admin, URL jurnal, dan dokumen panduan pengelolaan diserahkan via file. Kami tunjukkan cara mengelola jurnal — Anda bisa tanya langsung di sesi ini.

### FAQ

**Berapa lama sampai jurnal siap?**  
Instalasi standar: 2-3 hari kerja. Kalau server sudah siap, bisa lebih cepat. Untuk instalasi dengan custom theme, plugin khusus, atau migrasi dari OJS 2: 1-2 minggu. Estimasi detail diberikan setelah cek kebutuhan.

**Apakah bisa instalasi di server kampus yang sudah ada?**  
Ya. Kami install langsung di server Anda — VPS kampus, cloud, atau dedicated server. Syarat: akses SSH dan memenuhi spesifikasi teknis OJS. Kalau server belum ada, kami bantu siapkan.

**Apakah termasuk training untuk editor dan reviewer?**  
Dokumentasi pengelolaan selalu disertakan. Untuk training tim editor/ reviewer yang lebih mendalam (cara submit, cara review, cara publish), tersedia sebagai sesi terpisah — bisa via Zoom atau onsite.

**Bagaimana jika ingin upgrade dari OJS 2 ke OJS 3?**  
Kami berpengalaman melakukan migrasi OJS 2 ke 3 — termasuk untuk jurnal dengan ribuan artikel. Semua dilakukan di staging environment dulu (server terpisah, 100% kloningan jurnal asli). Upgrade baru dijalankan ke production setelah semua dicek: artikel lengkap, user bisa login, plugin berfungsi. **Nol data hilang.**

**Apakah ada garansi setelah instalasi?**  
Masa garansi 2 minggu untuk perbaikan bug terkait instalasi. Setelah itu, tersedia paket maintenance bulanan — sudah termasuk monitoring uptime, backup harian, dan update keamanan. Dengan maintenance, Anda tinggal fokus ke substansi artikel — kami urus teknisnya.

**Apakah Anda juga bisa bantu optimasi SEO jurnal?**  
Ya, termasuk dalam instalasi. Kami setup sitemap XML, meta tags Dublin Core, OAI-PMH, dan optimasi kecepatan halaman — semua fondasi teknis yang dibutuhkan jurnal untuk terindeks di Google Scholar, SINTA, dan DOAJ.
